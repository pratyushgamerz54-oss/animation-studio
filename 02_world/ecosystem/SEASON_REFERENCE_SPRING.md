# SEASONAL ENVIRONMENT REFERENCE — SPRING (Decision Sheet 01 §6)

**APPROVED:** Spring = the **proposed primary season** of the film. One season for all connected scenes; no seasonal change between
connected scenes unless the story requires it (story document NOT received yet → no change planned).

## 1. Look rules (all regions)
| Topic | Spring rule |
|---|---|
| Foliage | fresh, lush, light-to-mid greens; new leaves slightly yellow-green / copper-pink at twig tips (Peepal, oak) |
| Sunlight | natural spring sun: clear, slightly warm (≈ 5 500–6 000 K), soft haze in valleys in the morning; HDRI `kloofendal_48d_partly_cloudy_puresky` (day), `qwantani_dusk_2_puresky` (dusk) |
| Flowers | in bloom: Burans (red), primula, buttercup, wild daisy, Ashram marigold + tulsi; alpine: gentian, blue poppy, edelweiss, dwarf rhododendron (late spring at altitude) |
| Grass | green and growing; dry-grass asset only on paths / training-ground edge (worn ground, not seasonal dryness) |
| Kans grass | **green leafy clumps without white plumes** — plumes are an autumn feature and must not be the seasonal look |
| Snow | high peaks + glaciers keep snow (TASK 05 terrain unchanged); snow line not lowered |
| Water | spring melt: rivers full and clear, waterfalls strong (TASK 05 cascade), lake bays calm |

## 2. Per region
| Region | Spring identity |
|---|---|
| R-01 Ashram Valley | fresh greens; **red Burans** at grove edges and along the Ashram wall; Ashram garden vibrant (marigold orange/yellow, tulsi) under the landmark Peepal's new leaves; meadows with primula / buttercup / daisy |
| R-02 Enchanted Forest | new teal-green leaves, ferns unfurling, moss vivid; subtle glow only at night (unchanged by season) |
| R-03 Mountain Kingdom (Great Northern Range) | **red Burans in the lower montane belt (M1, 1 500–3 000 m)**, birch in fresh leaf at the tree line, alpine meadows greening, flowers late spring; snow above |
| R-06 Green Plains | tall fresh green grass, wildflower drifts |
| R-08 Crystal Lakes | fresh reeds + water-lily / lotus leaves, willows in new leaf |
| R-04 Golden Desert | brief green after spring rain only in wadis (shrubs), dunes unchanged |
| R-05 Forbidden Lands | no seasonal change (lifeless, approved TASK 05 look) |
| Sky Realms (PROPOSED region) | same spring look as the main world for its forests / waterfalls |
